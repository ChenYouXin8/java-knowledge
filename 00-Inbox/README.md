# 00-Inbox 📥

> **临时收集区** —— 看到文章、想起来的知识点、临时记的东西，先扔这里，每周整理一次。

## 使用规则

- 文件命名：`YYYY-MM-DD-主题.md`，例如 `2026-08-13-SpringAI术语.md`
- 不超过 1 周整理一次 → 移到对应正式分类
- 整理完的文件可以删掉，避免重复

## 整理去向参考

- Java 基础 → `01-Java基础/`
- Spring / Spring AI → `04-Spring生态/` 或 `05-AI应用开发/`
- 面试题 → `07-面试与项目/面试题/`
- 通用的 → 想想属于哪一类，分类没有就加
