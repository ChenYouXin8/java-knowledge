> 程序在**运行时**动态获取类的信息、调用任意方法。Spring / MyBatis / 框架底层全靠它。

---

## 1️⃣ 代码模板

### 1-1 获取 Class 对象的 3 种方式

```java
// 方式1：类名.class（最简洁，编译时确定）
Class<?> c1 = String.class;
Class<?> c2 = int.class;
Class<?> c3 = User.class;

// 方式2：对象.getClass()（运行时对象）
String s = "hello";
Class<?> c4 = s.getClass();

// 方式3：Class.forName("全限定类名")（最灵活，字符串驱动）
Class<?> c5 = Class.forName("java.lang.String");

// 注意：同一类的 Class 对象是同一个（单例，JVM 保证）
System.out.println(c1 == c4);  // true
System.out.println(c4 == c5);  // true
```

### 1-2 通过反射创建对象模板

```java
Class<?> c = Class.forName("com.example.User");

// 方式1：newInstance()（已过时，只能调无参构造）
Object obj = c.newInstance();

// 方式2：用 Constructor（推荐，支持有参构造）
Constructor<?> con = c.getDeclaredConstructor(String.class, int.class);
Object obj2 = con.newInstance("Tom", 18);

// 获取所有构造方法
Constructor<?>[] cons = c.getDeclaredConstructors();
for (Constructor<?> con2 : cons) {
    System.out.println(con2.getName() +
        " 参数数量:" + con2.getParameterCount());
}

// 调用私有构造（需 setAccessible）
Constructor<?> privateCon = c.getDeclaredConstructor(Long.class);
privateCon.setAccessible(true);  // 跳过权限检查
Object obj3 = privateCon.newInstance(1L);
```

### 1-3 调用方法的完整模板

```java
Class<?> c = User.class;
Object obj = c.getDeclaredConstructor().newInstance();

// 获取 public 方法
Method setName = c.getMethod("setName", String.class);
Method getName = c.getMethod("getName");

// 获取所有方法（包括 private）
Method[] allMethods = c.getDeclaredMethods();

// 获取 private 方法
Method privateMethod = c.getDeclaredMethod("doPrivate", null);
privateMethod.setAccessible(true);  // 必须设权限

// 调用方法
// invoke(对象, 参数...)
setName.invoke(obj, "Tom");
String name = (String) getName.invoke(obj);

// 调用静态方法（对象传 null）
Method staticMethod = c.getDeclaredMethod("getCount");
staticMethod.setAccessible(true);
int count = (int) staticMethod.invoke(null);  // null 表示调用静态方法

// 调用私有方法
privateMethod.invoke(obj);

// 处理返回数组的方法
Method arrMethod = c.getDeclaredMethod("getScores");
Object result = arrMethod.invoke(obj);
if (result instanceof String[] arr) {
    for (String s : arr) System.out.println(s);
}
```

### 1-4 操作字段模板

```java
Class<?> c = User.class;
Object obj = c.getDeclaredConstructor().newInstance();

// 获取 public 字段
Field publicField = c.getField("name");  // 只能 public

// 获取所有字段（包括 private）
Field[] allFields = c.getDeclaredFields();

// 获取 private 字段
Field privateField = c.getDeclaredField("age");
privateField.setAccessible(true);

// 读字段
String name = (String) privateField.get(obj);

// 写字段
privateField.set(obj, 20);

// 静态字段操作（对象传 null）
Field staticField = c.getDeclaredField("COUNT");
staticField.setAccessible(true);
Object val = staticField.get(null);  // 读静态字段
staticField.set(null, 100);          // 写静态字段
```

### 1-5 反射工厂模式模板

```java
// 配置文件驱动：classpath:service.properties
// user.service=com.example.impl.UserServiceImpl
// order.service=com.example.impl.OrderServiceImpl

public class ServiceFactory {
    private static final Map<String, Object> cache = new HashMap<>();

    public static <T> T getService(Class<T> interfaceClass) {
        String key = interfaceClass.getName();
        if (cache.containsKey(key)) {
            return interfaceClass.cast(cache.get(key));
        }

        try {
            Properties props = new Properties();
            props.load(ClassLoader.getSystemResourceAsStream("service.properties"));
            String implClass = props.getProperty(key);

            Class<?> clazz = Class.forName(implClass);
            Object instance = clazz.getDeclaredConstructor().newInstance();
            cache.put(key, instance);

            return interfaceClass.cast(instance);
        } catch (Exception e) {
            throw new RuntimeException("创建服务失败: " + key, e);
        }
    }
}

// 使用：完全不依赖具体实现类
UserService service = ServiceFactory.getService(UserService.class);
service.getUser(1L);
```

## 2️⃣ 对比表格

### 2-1 获取 Class 的 3 种方式对比

| 方式 | 代码 | 何时可用 | 触发 static 块 |
|------|------|---------|--------------|
| `ClassName.class` | `String.class` | 编译时已知 | ❌ |
| `obj.getClass()` | `"str".getClass()` | 运行时对象 | ❌ |
| `forName("包名")` | `Class.forName("java.lang.String")` | 字符串驱动 | ✅ |

### 2-2 getField vs getDeclaredField

| 方法 | 访问范围 | 查找方式 |
|------|---------|---------|
| `getField(name)` | 仅 public | 沿继承链向上查找 |
| `getDeclaredField(name)` | 包括 private | 仅当前类 |
| `getFields()` | 所有 public 字段 | 整个继承链 |
| `getDeclaredFields()` | 所有字段 | 仅当前类 |

### 2-3 反射 vs 直接调用

| 维度 | 直接调用 | 反射调用 |
|------|---------|---------|
| 性能 | 快（JIT 优化、内联） | 慢（动态解析、安全检查） |
| 类型安全 | 编译时检查 | 运行时才知对错 |
| 灵活性 | 差（硬编码） | 强（字符串驱动） |
| 使用场景 | 正常业务代码 | 框架、插件、通用工具 |

### 2-4 Class.forName vs ClassLoader.loadClass

| 维度 | `forName()` | `loadClass()` |
|------|------------|-------------|
| 初始化 | ✅（执行 static 块） | ❌ |
| 典型用途 | JDBC 驱动加载 | 插件懒加载、ClassPath 扫描 |
| 触发时机 | 立即初始化 | 首次使用时才初始化 |

## 3️⃣ 图解结构

### 3-1 Class 对象体系

```
┌──────────────────────────────────────────────┐
│                   Class<?>                    │
│  (类的类，JVM 为每个类只生成一个 Class 对象)   │
└──────────────────────────────────────────────┘
                ▲ is-a
                │
┌───────────────┼───────────────────────┐
│               │                        │
┌─▼────────┐ ┌──▼────────┐  ┌──────────▼──────────┐
│ Class     │ │ Constructor│  │ Method              │
│ (普通类)  │ │ (构造方法)  │  │ (成员方法)           │
└───────────┘ └───────────┘  └─────────────────────┘

┌──────────────────────────────────────────┐
│ 每个类在 JVM 中只有一个 Class 对象         │
│                                          │
│  String.class ──────┐                    │
│  "str".getClass()──┼──→ 同一个 Class 对象  │
│  Class.forName()───┘                     │
│                    (JVM 单例保证)          │
└──────────────────────────────────────────┘
```

### 3-2 反射调用流程

```
调用 setName(obj, "Tom")

① Class.forName("com.example.User")
   → 获取 User 类的 Class 对象

② class.getMethod("setName", String.class)
   → 在 Class 对象中查找方法签名
   → 找到 Method 对象

③ method.invoke(obj, "Tom")
   → 运行时调用 obj 的 setName 方法
   → 传入参数 "Tom"

编译时：完全不知道要调什么
运行时：根据字符串"setName"动态找到并调用
```

### 3-3 Spring IOC 反射原理

```
Spring 容器初始化：
1. 读取配置文件 <bean class="com.example.UserService">
2. Class.forName("com.example.UserService") → 获取 Class 对象
3. class.getDeclaredConstructor().newInstance() → 创建对象
4. 遍历所有 Field
5. 如果字段有 @Autowired 注解 → 反射注入依赖对象
```

## 4️⃣ 速查清单

### 4-1 常用反射方法速查

**Class 对象方法：**
| 方法 | 说明 |
|------|------|
| `getName()` | 全限定类名 |
| `getSimpleName()` | 简单类名 |
| `getPackage()` | 所在包 |
| `getSuperclass()` | 父类 |
| `getInterfaces()` | 实现的接口数组 |
| `getDeclaredMethods()` | 本类所有方法（含 private） |
| `getDeclaredFields()` | 本类所有字段（含 private） |
| `newInstance()` | 调用无参构造创建对象（已过时） |

**Method 方法：**
| 方法 | 说明 |
|------|------|
| `invoke(obj, args...)` | 调用方法 |
| `getName()` | 方法名 |
| `getReturnType()` | 返回类型 |
| `getParameterTypes()` | 参数类型数组 |
| `setAccessible(true)` | 跳过权限检查 |

**Field 方法：**
| 方法 | 说明 |
|------|------|
| `get(obj)` | 读字段值 |
| `set(obj, value)` | 写字段值 |
| `getName()` | 字段名 |
| `getType()` | 字段类型 |
| `setAccessible(true)` | 跳过权限检查 |

## ❓ 常见面试题

**Q1: 反射为什么慢？**
> 涉及动态解析（方法名/参数类型）、安全检查、`setAccessible` 开销、JIT 无法内联优化。现代 JVM 优化后差距已缩小（2~20倍），多数场景可忽略。

**Q2: 反射可以破坏单例吗？怎么防止？**
> 可以通过 `class.getDeclaredConstructor().newInstance()` 直接绕过。防御：在构造方法里检查实例是否已存在，抛异常。

**Q3: `Class.forName()` 和 `ClassLoader.loadClass()` 的区别？**
> 详见上方对比表格 2-4。JDBC 驱动加载必须用 `forName()`（触发 static 块注册 Driver）。

**Q4: 为什么 private 字段可以直接访问？**
> `field.setAccessible(true)` 跳过 JVM 安全检查。Spring/MyBatis 用它实现依赖注入和 ORM 映射。正常业务代码不应滥用。

**Q5: 如何用反射获取泛型类型？**
```java
// 反射可以获取方法参数类型，但泛型信息会被擦除
Type[] types = method.getGenericParameterTypes();
// 泛型声明类型可以获取：
Type type = ((ParameterizedType) field.getGenericType())
    .getActualTypeArguments()[0];
```

## 🐛 踩坑记录

- `getMethod()` 只查**公有**方法，`getDeclaredMethod()` 查**所有**方法
- 调用 `setAccessible(true)` 访问 private 成员会触发安全检查（SecurityManager 启用时）
- 反射调用泛型方法时泛型信息被擦除
- `newInstance()` 只能调**无参构造**，有参构造用 `Constructor`
- `getMethod()` 的第二个参数是**参数类型数组**，不是参数个数
