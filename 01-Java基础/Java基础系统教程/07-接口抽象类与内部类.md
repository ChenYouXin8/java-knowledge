# 第 7 章 接口、抽象类与内部类

## 本章目标
- 会定义和实现接口，理解接口的多实现与默认方法
- 分清抽象类与接口怎么选
- 认识四种内部类，理解匿名内部类与 Lambda 的关系
- 会用枚举 enum

---

## 7.1 抽象类与抽象方法

用 `abstract` 修饰的方法**只有声明没有方法体**；含抽象方法的类必须是抽象类。抽象类不能 new，用来被继承，强制子类实现抽象方法。

```java
abstract class Animal {
    String name;
    abstract void sound();       // 抽象方法：子类必须实现

    public void sleep() {        // 抽象类里也可以有普通方法
        System.out.println(name + " 睡觉");
    }
}

class Dog extends Animal {
    @Override
    void sound() { System.out.println("汪汪"); }
}
```

特点：
- 抽象类不能实例化，但可以有构造器（给子类 super 调用）。
- 子类若不实现全部抽象方法，子类也得是抽象类。

## 7.2 接口（interface）：定义"能做什么"的契约

接口是一套**行为规范/能力约定**，只规定"有什么方法"，不关心"怎么实现"。类用 `implements` 实现接口，且**可以实现多个接口**（弥补单继承）。

```java
interface Swimmable {
    void swim();     // 接口方法默认 public abstract，不用写
}
interface Flyable {
    void fly();
}

class Duck extends Animal implements Swimmable, Flyable {  // 多实现
    @Override public void sound() { System.out.println("嘎嘎"); }
    @Override public void swim()  { System.out.println("鸭子游"); }
    @Override public void fly()   { System.out.println("鸭子飞"); }
}
```

### JDK 8+ 接口的新特性（重要）
```java
interface Calculator {
    int add(int a, int b);                  // 抽象方法

    default int sub(int a, int b) {         // 默认方法：接口里可带实现，实现类可直接继承/重写
        return a - b;
    }

    static int mul(int a, int b) {          // 静态方法：用 接口名.mul 调
        return a * b;
    }
}
```
- 接口中的**常量**默认 `public static final`。
- JDK 9 起接口还支持 private 方法（给 default 方法复用）。

### 接口的多态
接口同样支持多态，这是 Spring 面向接口编程的核心：
```java
Swimmable s = new Duck();
s.swim();    // 面向接口，调用方不关心具体是谁
```

## 7.3 抽象类 vs 接口怎么选（高频面试）

| 对比点 | 抽象类 abstract class | 接口 interface |
|--------|----------------------|-----------------|
| 关系含义 | is-a（是什么） | can-do（能做什么 / 具备某能力） |
| 继承/实现 | 只能继承**一个** | 可实现**多个** |
| 构造器 | 有 | 没有 |
| 字段 | 普通字段都行 | 只能是 `public static final` 常量 |
| 方法 | 抽象/普通都行 | 抽象 + default/static（JDK8+） |
| 使用场景 | 多个子类共享**状态和代码** | 定义**规范/能力**，解耦 |

一句话：**"是什么"用抽象类，"能做什么"用接口；优先用接口定义行为，需要共享字段和通用实现时再用抽象类。**

## 7.4 内部类（了解，认识匿名内部类即可重点掌握）

定义在另一个类内部的类，分四种：

### ① 成员内部类
```java
class Outer {
    private int x = 1;
    class Inner { void show() { System.out.println(x); } } // 能直接访问外部类私有成员
}
new Outer().new Inner().show();
```

### ② 静态内部类（最常用，如 HashMap 的 Node、Builder 模式）
```java
class Outer {
    static class StaticInner { }
}
new Outer.StaticInner();
```

### ③ 局部内部类（定义在方法里，极少用）

### ④ 匿名内部类（重点！Lambda 的前身）
当你需要一个**只用一次的实现类对象**，不用专门建类，直接 new 接口并当场实现：

```java
Runnable task = new Runnable() {
    @Override
    public void run() { System.out.println("跑起来"); }
};
```

当接口**只有一个抽象方法（函数式接口）**时，JDK 8 的 Lambda 可以把它大幅简化（第 12 章细讲）：
```java
Runnable task = () -> System.out.println("跑起来");
```

## 7.5 枚举 enum：有限个固定取值

当一个变量只能取有限几个值时，用枚举代替魔法字符串/数字，更安全：

```java
enum Season { SPRING, SUMMER, AUTUMN, WINTER }

Season s = Season.SUMMER;
switch (s) {
    case SUMMER -> System.out.println("夏天");
    default -> System.out.println("其他");
}

// 枚举自带 values()、valueOf()
for (Season v : Season.values()) System.out.println(v);
```

枚举本质是一个 final 类，每个枚举项是它的单例对象，还可以带字段、构造器和方法，单例模式最佳实现就是枚举。

## 7.6 工程实践与踩坑
- 面向接口编程：方法参数、返回值、成员变量尽量声明为接口类型（`List` 而非 `ArrayList`），方便替换实现。
- 接口隔离：别设计一个"大而全"的胖接口，拆成多个小接口（接口隔离原则）。
- 一个类实现两个接口、两个接口有同名 default 方法时，实现类必须重写解决冲突。
- 枚举比较直接用双等号（`a == b`）即可（枚举是单例），不用 equals。

---

## 本章小结
- 抽象类用 abstract、不能 new、强制子类实现；接口是能力契约、可多实现。
- is-a 用抽象类，can-do 用接口；JDK8+ 接口可有 default/static 方法。
- 匿名内部类用于一次性实现，函数式接口可用 Lambda 简化。
- enum 用于有限固定取值，类型安全。
