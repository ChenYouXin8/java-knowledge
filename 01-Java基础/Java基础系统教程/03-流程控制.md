# 第 3 章 流程控制

## 本章目标
- 熟练使用 if / switch 做分支
- 熟练使用 for / while / do-while 做循环
- 分清 break、continue、return 的作用
- 能独立写出嵌套循环的小算法（九九乘法表等）

---

## 3.1 分支结构

### if 三种形态
```java
int score = 85;

// 1. 单分支
if (score >= 60) {
    System.out.println("及格");
}

// 2. 双分支
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// 3. 多分支
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

> 建议：哪怕只有一条语句也**保留大括号**，避免后续加代码时出错（Apple 曾因省略大括号导致著名 bug）。

### switch：适合"值的多选一"
传统写法（注意穿透）：
```java
int day = 3;
switch (day) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        System.out.println("工作日");
        break;              // 没有 break 会继续往下执行，叫"case 穿透"
    case 6:
    case 7:
        System.out.println("周末");
        break;
    default:
        System.out.println("非法");
}
```

JDK 14+ 的**箭头语法（推荐，无穿透，更简洁）**：
```java
String type = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "非法";
};   // switch 表达式可以直接返回值赋给变量
```

- `switch` 支持的类型：`byte/short/int/char`、它们的包装类、`String`、枚举。
- **if 适合区间判断，switch 适合固定值匹配。**

## 3.2 循环结构

### for：知道循环次数时首选
```java
// 求 1~100 的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println(sum); // 5050
```
执行顺序：初始化① → 判断② → 循环体③ → 迭代④，之后重复 ②③④。

### while：不知道次数，知道结束条件
```java
int money = 0;
while (money < 100) {   // 先判断再执行
    money += 30;
}
```

### do-while：至少执行一次
```java
int n = 0;
do {
    System.out.println(n);
    n++;
} while (n < 3);   // 先执行一次再判断
```

### 增强 for（for-each，遍历数组/集合，第 4、11 章常用）
```java
int[] nums = {1, 2, 3};
for (int x : nums) {     // 依次取出每个元素，不需要下标
    System.out.println(x);
}
```

## 3.3 break、continue、return 的区别（高频面试）

| 关键字 | 作用 |
|--------|------|
| `break` | **立刻结束当前所在的整个循环**，跳到循环之后 |
| `continue` | **跳过本次**循环剩余语句，直接进入下一次迭代 |
| `return` | 结束整个**方法**（不只是循环） |

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;  // 跳过 3：输出 1 2 4 5
    System.out.println(i);
}

for (int i = 1; i <= 5; i++) {
    if (i == 3) break;     // 到 3 就停：输出 1 2
    System.out.println(i);
}
```

嵌套循环中想**直接跳出外层**，用带标签的 break（了解即可）：
```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break outer;  // 直接跳出标记为 outer 的外层循环
    }
}
```

## 3.4 经典练习：九九乘法表（嵌套循环必练）

```java
for (int i = 1; i <= 9; i++) {          // 外层控制行
    for (int j = 1; j <= i; j++) {      // 内层控制列
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println();               // 每行结束换行
}
```

要点：外层走一次、内层走一遍；`print` 不换行、`println` 换行。

## 3.5 工程实践与踩坑
- 小心**死循环**：`for(;;)` 和 `while(true)` 都是死循环，必须有退出条件。
- 浮点数不要做循环变量（精度累积会出错）。
- 循环里能少做的事就提到循环外（比如别在循环里重复 new 对象、重复查数据库）。
- 多层嵌套超过 3 层就要考虑拆方法，可读性优先。

---

## 本章小结
- 区间判断用 if-else if-else，固定值匹配用 switch（JDK14+ 优先箭头语法）。
- 知次数用 for，知条件用 while，至少执行一次用 do-while。
- break 结束整个循环，continue 跳过本次，return 结束整个方法。
