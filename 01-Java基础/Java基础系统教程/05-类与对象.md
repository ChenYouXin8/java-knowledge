## 5.1 面向对象到底是什么

**面向过程**：一步步写"怎么做"（先淘米、再放水、再按开关）。
**面向对象（OOP）**：先找"谁来做"，把数据和操作数据的方法封装成对象（电饭煲对象自己会煮饭，你只需调用它）。

核心关系：
- **类（class）**：一张设计图纸 / 模板，描述一类事物有什么**属性（字段）**和**行为（方法）**。
- **对象（object / 实例 instance）**：按图纸 new 出来的具体个体。一个类可以 new 无数个对象。

```java
// 类：图纸
public class Dog {
    // 字段（属性）
    String name;
    int age;

    // 方法（行为）
    void bark() {
        System.out.println(name + " 汪汪叫");
    }
}
```

```java
public class Test {
    public static void main(String[] args) {
        Dog d = new Dog();   // 用 new 创建对象（实例化）
        d.name = "旺财";      // 给字段赋值
        d.age = 3;
        d.bark();            // 调用方法：旺财 汪汪叫
    }
}
```

内存理解：`Dog d` 在栈里存地址，真正的对象在堆里。

## 5.2 封装与标准 JavaBean（最重要的写法）

**封装**：把字段藏起来（`private`），只通过公开的 get/set 方法访问，从而能在方法里加校验、保护数据。这就是"高内聚、低耦合"的起点。

标准类（JavaBean / POJO）四件套：**私有字段、无参构造、有参构造、getter/setter**（IDEA 中 `Alt+Insert` 一键生成）。

```java
public class Student {
    // 1. 私有字段
    private String name;
    private int age;

    // 2. 无参构造器（手写了有参后，无参不会自动生成，建议显式写出）
    public Student() {}

    // 3. 有参构造器：new 的同时赋值
    public Student(String name, int age) {
        this.name = name;
        setAge(age);          // 走 setter，复用校验逻辑
    }

    // 4. getter / setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄不合法: " + age);
        }
        this.age = age;       // 封装的价值：赋值前能校验
    }
}
```

## 5.3 构造器（构造方法）

- 名字与类名完全相同、**没有返回类型**、new 对象时自动调用，用于初始化。
- 不写任何构造器，编译器送一个默认无参构造；一旦自己写了有参，默认无参就没了。
- 构造器之间可以用 `this(...)` 重载互调，且必须在第一行。

```java
public Student() { this("未命名", 18); }   // 调用本类另一个构造器
public Student(String name, int age) { this.name = name; this.age = age; }
```

---

## 5.4 this 关键字三种用法

| 用法 | 含义 |
|------|------|
| `this.字段` | 当前对象的字段，解决局部变量与字段同名（最常用） |
| `this.方法()` | 调用当前对象的方法（this 可省略） |
| `this(...)` | 调用本类其他构造器，必须在第一行 |

记忆：**this 代表"当前这个对象自己"。**

## 5.5 static：属于类，不属于对象

- `static` 修饰的成员（静态变量 / 静态方法）**属于类**，全类共享一份，用 `类名.` 直接访问，不需要 new。
- 非静态成员属于对象，每个对象各一份。

```java
class Counter {
    static int total = 0;     // 静态变量：所有对象共享
    int id;                   // 实例变量：每个对象一份

    Counter() { total++; }
}
```

```java
public class MathTool {
    public static int square(int x) { return x * x; }  // 工具方法用 static
}
// 调用：MathTool.square(5)，不用 new
```

静态使用规则（面试常考）：
- **静态方法里不能直接用非静态成员 / this**（静态方法加载时可能还没有对象）。
- 非静态方法里可以直接访问静态成员。
- `static` 代码块在类加载时执行一次，常用于初始化静态资源。

```java
static { /* 类加载时执行一次 */ }
{ /* 实例代码块：每次 new 都执行，先于构造器 */ }
```

## 5.6 包（package）与访问修饰符

包就是类的"文件夹 + 命名空间"，避免类重名，公司习惯用域名倒写：`com.chen.demo`。
- `package` 声明必须在源文件第一行；用别的包的类要 `import`。
- `java.lang` 包（String、Math、System）自动导入，不用写 import。

四种访问权限（从宽到窄）：

| 修饰符 | 本类 | 同包 | 不同包子类 | 任意地方 |
|--------|:---:|:---:|:---:|:---:|
| `public` | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| （默认/包私有，不写） | ✅ | ✅ | ❌ | ❌ |
| `private` | ✅ | ❌ | ❌ | ❌ |

原则：**字段尽量 private，对外方法才 public**，能不暴露就不暴露（最小权限原则）。

## 5.7 Java 到底是值传递还是引用传递（经典面试）

**Java 只有值传递**：方法传参，传的是"值的副本"。
- 基本类型：传的是值的拷贝，方法里改副本不影响外面。
- 引用类型：传的是**地址值的拷贝**，副本和原引用指向同一个堆对象，所以通过它改对象内容会影响外面；但把副本重新指向新对象，不影响原引用。

```java
void change(User u) { u.setName("新名字"); } // 外面的对象内容会变
void rePoint(User u) { u = new User(); }     // 外面的引用不会被改指向
```

## 5.8 工程实践与踩坑（Effective Java 风格）
- 字段一律 private，通过 get/set 或构造器暴露，杜绝 `public` 字段。
- 不可变对象优先（字段 final + 不提供 set），线程更安全，如 String。
- 工具类构造器设为 private，防止被 new。
- 别在构造器里调用可被子类重写的方法（会引发初始化问题，第 6 章会遇到）。

## 本章小结
- 类是模板，对象是 new 出来的实例；封装 = private 字段 + get/set。
- 标准 JavaBean：私有字段、无参/有参构造、getter/setter。
- this 指当前对象；static 属于类、共享一份；权限遵循最小化。
- Java 只有值传递，引用类型传的是地址值的副本。
