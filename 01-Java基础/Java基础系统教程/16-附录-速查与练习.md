# 附录 A 命令速查、常见错误与练习参考

## A.1 命令行速查

```bash
javac HelloWorld.java        # 编译源码为 .class
java HelloWorld              # 运行（不带 .class）
java -version                # 查看 JDK 版本
javac -encoding UTF-8 X.java # 指定编码编译（中文源码防乱码）
jar -cvf app.jar .           # 打包
```

## A.3 新手高频报错速查（看到别慌）

| 报错信息 | 原因 | 解决 |
|----------|------|------|
| `class X is public, should be declared in file X.java` | public 类名与文件名不一致 | 改文件名或类名，使其一致 |
| `cannot find symbol` | 变量/方法没定义、拼错、没导包 | 检查拼写、Alt+Enter 导包 |
| `';' expected` | 漏了分号/括号 | 定位行号补全 |
| `incompatible types: possible lossy conversion` | 大类型赋给小类型缺强转 | 加 `(类型)` 强转 |
| `NullPointerException` | 对 null 调方法/取属性 | 先判空，定位谁是 null |
| `ArrayIndexOutOfBoundsException` | 数组下标越界 | 检查下标范围 0~length-1 |
| `ClassCastException` | 错误的向下转型 | 先 instanceof 判断 |
| `NumberFormatException` | 字符串转数字格式不对 | 校验输入格式 |
| `ConcurrentModificationException` | 遍历时直接删集合元素 | 用 Iterator.remove/removeIf |
| 中文乱码 | 编码不一致 | 统一 UTF-8，编译加 -encoding |

## A.4 各章动手练习参考思路

> 只给关键思路，代码请自己敲出来——自己写会才是真会。

**第 2 章**
- 三个数最大值：`int max = a > b ? (a > c ? a : c) : (b > c ? b : c);`
- 交换两变量：①临时变量（推荐）②`a=a+b;b=a-b;a=a-b;`（有溢出风险）③`a^=b;b^=a;a^=b;`

**第 3 章**
- 判断质数：从 2 遍历到 `√n`，若有能整除的就不是质数。
- 折纸次数：`while(厚度 < 8848000){厚度*=2;次数++;}`（注意单位都换算成毫米）。

**第 4 章**
- 最大/最小/平均：先假设第一个为最值，遍历更新；平均用 `(double)sum/length`。
- 冒泡：外层 n-1 轮，内层相邻比较交换（见 4.6）。

**第 5 章**
- BankAccount：余额 private，withdraw 里 `if(money>balance) throw new BizException(...)`。
- 统计 new 数量：构造器里 `count++`，count 用 static。

**第 6 章**
- 图形面积：`Shape[]` 装 Circle/Rectangle，循环 `sum += s.area()`，这就是多态。
- 初始化顺序：父静→子静→父实例块/构造→子实例块/构造。

**第 7 章**
- 支付：`Payable[]` 装不同支付实现，遍历 `pay()`，面向接口。
- 枚举判工作日：switch 表达式 `switch(day){case MON..FRI -> "工作日"; ...}`。

**第 8 章**
- 字符计数：`Map<Character,Integer>` + `getOrDefault(c,0)+1`。
- 出生天数：`ChronoUnit.DAYS.between(birth, LocalDate.now())`。

**第 9 章**
- 相除处理：分别 catch NumberFormatException、ArithmeticException。
- 自定义异常继承 RuntimeException，带构造方法调 super(message)。

**第 10 章**
- 反转 List 泛型方法：`public static <T> List<T> reverse(List<T> src)`，新建结果从尾到头 add。

**第 11 章**
- 词频：`map.put(w, map.getOrDefault(w,0)+1)`。
- 保序去重：把 List 传入 `new LinkedHashSet<>(list)`，再转回 List。

**第 12 章**
- 偶数平方去重：`list.stream().filter(x->x%2==0).map(x->x*x).distinct().toList()`。
- 分组平均：`collect(groupingBy(班级, averagingInt(分数)))`。

**第 13 章**
- 统计行数：`Files.lines(path).count()`；关键词行数用 filter+count。

**第 14 章**
- 反射调私有：getDeclaredMethod → setAccessible(true) → invoke。
- 读注解：方法上 `getAnnotation(MyLog.class)`，前提 @Retention(RUNTIME)。

**第 15 章**
- 非线程安全计数：10 线程各 +1000，结果常 < 10000；方法加 synchronized 后稳定为 10000。

## A.5 核心术语表

| 术语 | 一句话解释 |
|------|-----------|
| JVM/JDK/JRE | 虚拟机 / 开发包(含JRE+工具) / 运行环境(含JVM+类库) |
| 面向对象 | 以对象为中心，封装/继承/多态三大特性 |
| 封装 | 隐藏内部状态，通过方法受控访问 |
| 继承 | 子类复用父类，is-a，Java 单继承 |
| 多态 | 父类引用指向子类对象，运行时动态绑定 |
| 重载/重写 | 同类同名不同参 / 父子类同方法改实现 |
| 接口/抽象类 | can-do 契约可多实现 / is-a 共享代码单继承 |
| 自动装箱 | 基本类型与包装类自动互转 |
| 不可变 | String 创建后内容不可改，修改返回新对象 |
| 泛型 | 参数化类型，编译期类型安全 |
| 类型擦除 | 泛型只在编译期，运行时被擦除 |
| 受检异常 | 编译期强制处理的异常（IOException 等） |
| 反射 | 运行时动态获取类信息、操作成员 |
| 注解 | 贴在代码上的元数据标签 |
| 线程安全 | 多线程并发下结果仍正确 |
