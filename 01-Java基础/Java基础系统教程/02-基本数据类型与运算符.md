# 第 2 章 基本数据类型与运算符

## 本章目标
- 记住 Java 的 8 种基本类型及其大小、默认值
- 会声明变量、理解自动/强制类型转换
- 熟练使用各类运算符，看懂 `i++` 与 `++i` 的区别

---

## 2.1 变量与常量

变量就是"一块有名字的内存空间"，用来存数据。Java 是**强类型语言**，变量必须先声明类型再使用：

```java
int age = 20;            // 声明并赋值
final double PI = 3.14;  // final 修饰的是常量，只能赋一次值，习惯全大写
age = 21;                // 变量可重新赋值
// PI = 3.15;            // 编译错误：常量不能再改
```

标识符（变量/类/方法名）规则：字母/数字/下划线/`$`，不能数字开头，不能用关键字（int、class 等），**区分大小写**，习惯用小驼峰 `userName`。

---

## 2.2 八大基本数据类型（必背表）

Java 的类型分两大类：**基本类型**（8 种，存值本身）和**引用类型**（类、接口、数组，存地址，第 5 章细讲）。

| 分类 | 类型 | 占用 | 取值范围 / 说明 | 默认值 |
|------|------|------|------------------|--------|
| 整数 | `byte` | 1 字节 | -128 ~ 127 | 0 |
| 整数 | `short` | 2 字节 | -32768 ~ 32767 | 0 |
| 整数 | **`int`** | 4 字节 | 约 ±21 亿，**整数默认 int** | 0 |
| 整数 | `long` | 8 字节 | 很大，字面量要加 `L` | 0L |
| 浮点 | `float` | 4 字节 | 单精度，字面量加 `F` | 0.0f |
| 浮点 | **`double`** | 8 字节 | 双精度，**小数默认 double** | 0.0d |
| 字符 | `char` | 2 字节 | 单个字符，用单引号 `'A'`，存 Unicode | '\u0000' |
| 布尔 | `boolean` | — | 只有 `true` / `false` | false |

```java
long big = 10000000000L;     // 不加 L，整数按 int 处理会溢出报错
float f = 3.14F;             // 不加 F，3.14 默认 double，赋给 float 报错
char c = '中';               // char 能存一个中文字符（Unicode）
boolean ok = true;
```

> 为什么 `char` 是 2 字节？因为 Java 用 Unicode 编码，一个字符占 2 字节，所以能直接存中文。

### 整数的三种进制写法
```java
int a = 10;      // 十进制
int b = 0b1010;  // 二进制，0b 开头
int o = 012;     // 八进制，0 开头
int h = 0xA;     // 十六进制，0x 开头
```

## 2.3 类型转换：自动 vs 强制

**自动类型转换（隐式，小 → 大，安全）**：取值范围小的类型可以自动转成大的。

```
byte → short → int → long → float → double
                char ↗
```

```java
int i = 100;
double d = i;   // 自动转换，d = 100.0
```

**强制类型转换（显式，大 → 小，可能丢精度，要手动写）**：

```java
double pi = 3.99;
int x = (int) pi;   // 结果 x = 3，小数部分直接截断（不是四舍五入！）

int big = 300;
byte b = (byte) big; // 溢出：300 超出 byte 范围，结果是 44，要警惕
```

> 规则记忆：**小转大自动，大转小强转；强转可能丢精度或溢出。**
> 特例：`byte/short/char` 参与运算时会先自动提升为 `int`。

```java
byte b1 = 3, b2 = 4;
// byte b3 = b1 + b2;   // 编译错误：运算时提升为 int，结果是 int
byte b3 = (byte)(b1 + b2);  // 必须强转
```

## 2.4 运算符

### 算术运算符
`+ - * / % ++ --`

```java
System.out.println(7 / 2);    // 3，两个 int 相除是整除
System.out.println(7.0 / 2);  // 3.5，有小数才保留小数
System.out.println(7 % 2);    // 1，取余，常用于判断奇偶、整除

int n = 5;
System.out.println(n++);  // 5：先用后加（先取当前值，再 +1）
System.out.println(++n);  // 7：先加后用
```

`++` 口诀：**符号在前先加再用，符号在后先用再加。**

`+` 遇到字符串变成**拼接**：
```java
System.out.println("结果=" + 1 + 2); // 结果=12（从左到右，先拼"结果=1"再拼2）
System.out.println(1 + 2 + "结果");  // 3结果（先算 1+2=3，再拼接）
```

### 赋值运算符

赋值号与复合赋值运算符（复合赋值自带强转）：

```text
=    +=    -=    *=    /=    %=
```

```java
byte b = 10;
b += 5;   // 等价于 b = (byte)(b + 5)，不会报错
```

### 比较运算符

比较运算符的结果一定是 boolean（true 或 false）。以 `int a = 3, b = 5;` 为例：

| 运算 | 写法 | 含义 | 结果 |
|------|------|------|------|
| 相等 | `a == b` | 两边是否相等（双等号，别和赋值 `a = b` 搞混） | false |
| 不等 | `a != b` | 是否不相等 | true |
| 大于 | `b > a` | 左边是否大于右边 | true |
| 小于 | `a < b` | 左边是否小于右边 | true |
| 大于等于 | `b >= a` | 是否大于或等于 | true |
| 小于等于 | `a <= b` | 是否小于或等于 | false |

#### 重点：双等号到底在比较什么（高频踩坑）

| 比较的数据 | 双等号的行为 | 想判断"内容相等"该怎么做 |
|------------|-------------|--------------------------|
| 整数 / char / boolean（基本类型） | 直接比值，正确，放心用 | 直接写 `a == b` |
| float / double（浮点基本类型） | 因精度误差，可能判断错误 | 比较两数差值的绝对值是否足够小 |
| String 等引用类型（对象、数组） | 比的是**内存地址**，不是内容 | 用 `a.equals(b)` 比内容 |

```java
// 1) 基本类型比值：正常
System.out.println(3 == 3);           // true

// 2) 浮点不要直接用 ==
System.out.println(0.1 + 0.2 == 0.3); // false！浮点误差，结果其实是 0.30000000000000004
double x = 0.1 + 0.2;
System.out.println(Math.abs(x - 0.3) < 1e-9);  // true：差值足够小才算相等

// 3) 引用类型：== 比地址，equals 比内容
String s1 = new String("abc");
String s2 = new String("abc");
System.out.println(s1 == s2);         // false：两个对象地址不同
System.out.println(s1.equals(s2));    // true：内容相同
```

> 一句话：基本类型比值用双等号（形如 `a == b`），浮点比差值，对象比内容用 `a.equals(b)`；String 的常量池等细节在第 8 章展开。

### 逻辑运算符
`&&`（短路与）、`||`（短路或）、`!`（非）

```java
// 短路：&& 左边为 false，右边根本不执行；|| 左边为 true，右边不执行
int x = 0;
if (x != 0 && 10 / x > 1) { }  // 安全：x!=0 为 false，后面不执行，不会除零
```

### 三元运算符
`条件 ? 值1 : 值2` —— 条件为真取值 1，否则取值 2：
```java
int score = 58;
String result = score >= 60 ? "及格" : "不及格";  // 不及格
```

### 位运算符（了解）
`& | ^ ~ << >> >>>`，面试可能问，实际业务少用。`<<` 左移一位相当于 ×2，`>>` 右移一位相当于 ÷2。

## 2.5 运算符优先级（不用死背，用括号最清晰）

口诀：**单目 > 算术 > 移位 > 比较 > 逻辑 > 三元 > 赋值**。实际开发中**不确定就加括号**，可读性优先。

---

## 2.6 工程实践与踩坑
- 金额计算**不要用 `double`**（浮点有精度误差，例如 0.1 加 0.2 不等于 0.3），用 `BigDecimal`（第 8 章）。
- 循环计数器、数组下标用 `int`；数据库主键、时间戳这种很大的整数用 `long` 并加 `L`。
- 布尔判断直接写变量名：用 `if (flag)`，不要写 `if (flag == true)`，更专业。
- 相等判断分清对象：基本类型用双等号（`a == b`），对象内容用 `a.equals(b)`，浮点比差值（见 2.4 比较运算符）。

---

## 本章小结
- 8 种基本类型：4 整 2 浮 1 字符 1 布尔；整数默认 int、小数默认 double。
- 小转大自动，大转小强转且可能丢精度；`byte/short/char` 运算提升为 int。
- `++` 在前在后有区别；`+` 遇字符串变拼接；逻辑运算有短路。
