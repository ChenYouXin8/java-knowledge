# 第 11 章 集合框架

## 本章目标
- 理清 Collection / Map 两大体系与选用
- 熟练使用 List / Set / Map 及其常用方法
- 理解 ArrayList 与 LinkedList、HashMap 底层原理入门
- 会用迭代器、Collections 工具、遍历方式选择

> 集合是日常开发和面试的绝对重点，本章讲清用法与原理，速查表见上层 `集合框架.md`。

---

## 11.1 集合框架全景图

数组定长，集合**长度可变、只存引用类型、自带常用算法**。两大阵营：

```
Collection（单个元素的集合，接口）
├── List（有序、可重复、有下标）
│    ├── ArrayList   ：数组实现，查询快、增删慢【最常用】
│    ├── LinkedList  ：链表实现，增删快、查询慢
│    └── Vector       ：古老、线程安全、慢（基本不用）
├── Set（无序、不重复）
│    ├── HashSet     ：哈希表，去重、无序【最常用】
│    ├── LinkedHashSet：哈希表+链表，去重且保留插入顺序
│    └── TreeSet     ：红黑树，自动排序
└── Queue / Deque（队列/双端队列）

Map（键值对 key-value，key 不重复，独立接口）
├── HashMap        ：哈希表，key 无序【最常用】
├── LinkedHashMap  ：保留插入/访问顺序
├── TreeMap        ：key 自动排序
└── Hashtable      ：古老、线程安全、慢（用 ConcurrentHashMap 替代）
```

---

## 11.2 List：有序可重复

### ArrayList 基本操作
```java
import java.util.*;

List<String> list = new ArrayList<>();
list.add("a");          // 末尾添加
list.add(0, "b");       // 指定下标插入
list.get(0);            // 按下标取
list.set(0, "c");       // 修改
list.remove(0);         // 按下标删
list.remove("a");       // 按内容删
list.size();            // 元素个数
list.contains("a");     // 是否包含
list.indexOf("a");      // 下标，找不到 -1
list.isEmpty();         // 是否为空
list.clear();           // 清空
```

### 三种遍历
```java
// 1. 普通 for（需要下标 / 删除元素时）
for (int i = 0; i < list.size(); i++) System.out.println(list.get(i));
// 2. 增强 for（最常用，只读遍历）
for (String s : list) System.out.println(s);
// 3. forEach + Lambda（第 12 章）
list.forEach(System.out::println);
```

### ArrayList vs LinkedList（面试）
| | ArrayList | LinkedList |
|---|---|---|
| 底层 | 动态数组 | 双向链表 |
| 随机访问 get | O(1)，快 | O(n)，慢 |
| 头尾增删 | 可能扩容/搬移 | O(1)，快 |
| 内存 | 紧凑、有预留空间 | 每节点多存前后指针 |
| 使用 | **90% 场景用它** | 频繁头尾增删才考虑 |

ArrayList 扩容：默认容量 10，满了扩容为原来的 **1.5 倍**（Arrays.copyOf 拷贝），所以**已知大小时 `new ArrayList<>(预估容量)` 可避免频繁扩容**。

## 11.3 Set：去重

```java
Set<String> set = new HashSet<>();
set.add("a"); set.add("a");   // 重复元素加不进去
System.out.println(set.size()); // 1
// 遍历只能用增强 for / forEach / Iterator，没有下标
for (String s : set) System.out.println(s);
```

- **HashSet 去重原理**：先比 `hashCode()`，相同再比 `equals()`，都相同才认为重复。所以**自定义对象放进 HashSet / 作 HashMap 的 key，必须重写 hashCode 和 equals**（IDEA 一键生成）。
- 需要排序用 `TreeSet`（元素实现 Comparable 或传 Comparator）；要保留插入顺序用 `LinkedHashSet`。

## 11.4 Map：键值对（最高频）

```java
Map<String, Integer> map = new HashMap<>();
map.put("apple", 3);      // 存 / 覆盖
map.get("apple");         // 按 key 取，没有返回 null
map.getOrDefault("x", 0); // 没有就给默认值（统计超常用）
map.containsKey("apple"); // 是否有此 key
map.containsValue(3);     // 是否有此 value
map.remove("apple");      // 删
map.size(); map.isEmpty(); map.clear();
```

### 三种遍历（面试常问）
```java
// 1. 遍历 key，再 get（只需要 key 时）
for (String k : map.keySet()) System.out.println(k + "=" + map.get(k));

// 2. entrySet 同时取 key-value（推荐，效率高）
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}

// 3. forEach（最简洁）
map.forEach((k, v) -> System.out.println(k + "=" + v));
```

### 经典用法：统计词频
```java
String[] words = {"a","b","a","c","a","b"};
Map<String, Integer> count = new HashMap<>();
for (String w : words) {
    count.put(w, count.getOrDefault(w, 0) + 1);
}
// {a=3, b=2, c=1}
```

### HashMap 底层原理入门（面试必背）
- JDK 8：**数组 + 链表 + 红黑树**。put 时先算 key 的 hash 定位数组桶。
- 桶为空直接放；桶里有元素则用 equals 比较，相同覆盖、不同挂链表。
- **链表长度 ≥ 8 且数组长度 ≥ 64 时，链表转红黑树**；节点数 ≤ 6 退化回链表（提高查询效率）。
- 默认初始容量 16、负载因子 0.75，元素数超过 `容量×0.75` 就**扩容为 2 倍**。
- HashMap **线程不安全**；并发场景用 `ConcurrentHashMap`（绝不用 Hashtable/Collections.synchronizedMap）。

## 11.5 Iterator 与遍历时删除

```java
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.equals("x")) it.remove();   // 用迭代器自己的 remove，安全
}
```
> 踩坑：增强 for 里直接 `list.remove(...)` 会抛 `ConcurrentModificationException`（并发修改异常）。要边遍历边删，用 Iterator.remove，或 JDK8 的 `removeIf`：`list.removeIf(s -> s.equals("x"))`。

## 11.6 Collections 工具类

```java
Collections.sort(list);               // 自然排序
Collections.sort(list, comparator);   // 自定义排序
Collections.reverse(list);            // 反转
Collections.shuffle(list);            // 随机打乱
Collections.max/min(list);            // 最大最小
Collections.unmodifiableList(list);   // 返回不可修改视图
```

自定义排序用 Comparator（配合 Lambda 更简洁，第 12 章）：
```java
list.sort(Comparator.comparing(Student::getAge));  // 按年龄升序
list.sort(Comparator.comparing(Student::getAge).reversed()); // 降序
```

## 11.7 怎么选集合（决策速记）
- 要**有序、按下标、可重复** → `ArrayList`
- 要**去重** → `HashSet`；去重且保序 → `LinkedHashSet`；要排序 → `TreeSet`
- 要**键值对** → `HashMap`；保序 → `LinkedHashMap`；key 排序 → `TreeMap`
- 并发 → `CopyOnWriteArrayList` / `ConcurrentHashMap`
- 队列/栈 → `ArrayDeque`（实现了 Deque，可当队列和栈）

---

## 11.8 工程实践与踩坑
- 声明用接口类型：`List<User> list = new ArrayList<>();`（多态，方便替换实现）。
- 自定义对象做 key / 放 Set，必须重写 equals 和 hashCode。
- HashMap 的 key 用不可变类型（String、Integer 最合适）。
- 已知元素数量就指定初始容量，减少扩容。
- 遍历中删除用 Iterator.remove 或 removeIf，别在增强 for 里直接删。
- 集合只能装包装类型，`List<int>` 非法，用 `List<Integer>`。

## 本章小结
- Collection 装单个元素（List 有序可重复、Set 去重），Map 装键值对。
- 90% 场景：ArrayList + HashMap；去重 HashSet；排序 TreeXxx。
- HashMap = 数组+链表+红黑树，链表 ≥8 且容量 ≥64 转树，负载因子 0.75 扩容 2 倍。
- 遍历时删除用 Iterator/removeIf；自定义 key 要重写 equals+hashCode。
