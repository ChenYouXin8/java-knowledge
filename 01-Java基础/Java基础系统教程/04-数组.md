# 第 4 章 数组

## 本章目标
- 理解数组是"固定长度、同类型"的容器及其内存模型
- 会声明、初始化、遍历一维和二维数组
- 熟练使用 `Arrays` 工具类
- 掌握排序、查找等数组常见算法

---

## 4.1 数组是什么

数组用来**一次性存多个相同类型的数据**，特点：
- 长度在创建时确定，**定长，不能增减**（要变长用集合，第 11 章）。
- 元素类型相同。
- 下标从 **0** 开始，最大下标 = 长度 - 1。
- 数组是**引用类型**，变量里存的是堆内存的地址。

内存模型（重要）：
```
栈(stack)                堆(heap)
int[] arr  ───────►  [ 10 | 20 | 30 ]   长度 3，下标 0~2
（存地址）              下标  0   1   2
```

## 4.2 声明与初始化

```java
// 1. 静态初始化：已知元素
int[] a = {1, 2, 3};
int[] b = new int[]{1, 2, 3};   // 完整写法

// 2. 动态初始化：只定长度，元素取默认值
int[] c = new int[3];           // [0, 0, 0]，整数默认 0
boolean[] d = new boolean[2];   // [false, false]
String[] s = new String[2];     // [null, null]，引用类型默认 null

// 访问与赋值
c[0] = 10;
System.out.println(c.length);  // 3，length 是属性，没有括号
```

各类型数组元素默认值：整数 0、浮点 0.0、char `\u0000`、boolean false、引用类型 null。

> 踩坑：访问 `c[3]` 会抛 `ArrayIndexOutOfBoundsException`（数组下标越界，新手高频异常）。

## 4.3 遍历数组

```java
int[] arr = {10, 20, 30};

// 方式 1：普通 for（需要下标时用）
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// 方式 2：增强 for（只需要元素、不需要下标时，最简洁）
for (int x : arr) {
    System.out.println(x);
}
```

---

## 4.4 二维数组（理解为"数组的数组"）

```java
// 静态
int[][] m = {{1, 2}, {3, 4, 5}};

// 动态：3 行 4 列
int[][] table = new int[3][4];

// 遍历：外层遍历行，内层遍历列
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) {
        System.out.print(m[i][j] + " ");
    }
    System.out.println();
}
```

二维数组内存并不要求规则，每一行长度可以不同（锯齿数组）。

## 4.5 Arrays 工具类（`java.util.Arrays`，必会）

```java
import java.util.Arrays;

int[] a = {3, 1, 2};

Arrays.toString(a);        // "[3, 1, 2]"，打印数组别再自己循环
Arrays.sort(a);            // 升序排序（原地），结果 [1, 2, 3]
Arrays.binarySearch(a, 2); // 二分查找（必须先排序），返回下标
Arrays.copyOf(a, 5);       // 复制并可改变长度，常用于"扩容"
Arrays.fill(a, 0);         // 全部填充为 0
int[] c = Arrays.copyOf(a, a.length); // 数组拷贝
Arrays.equals(a, c);       // 逐元素比较内容是否相等（a==c 比的是地址！）
```

> 关键区别：`a == c` 比的是两个引用是否指向同一地址；`Arrays.equals` 才是比内容。

## 4.6 经典算法（面试手写常考）

### 冒泡排序
```java
for (int i = 0; i < a.length - 1; i++) {
    for (int j = 0; j < a.length - 1 - i; j++) {
        if (a[j] > a[j + 1]) {          // 相邻比较，大的往后冒
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
        }
    }
}
```

### 求最大值 / 最小值
```java
int max = a[0];
for (int x : a) if (x > max) max = x;
```

### 反转数组
```java
for (int i = 0, j = a.length - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
```

## 4.7 工程实践与踩坑
- 业务中**长度可变、要频繁增删**的数据，别用数组，用 `ArrayList`（第 11 章）。
- 数组作为方法参数传递的是**地址**，方法内改元素会影响原数组（引用传递的效果）。
- 返回数组 / 集合而不是多个零散变量，是常见的整洁做法。
- `Arrays.asList(T...)` 返回的 List **不能 add/remove**（固定大小），新手易踩。

## 本章小结
- 数组定长、同类型、下标从 0 开始，是引用类型，越界抛异常。
- 遍历优先用增强 for；打印、排序、拷贝、查找直接用 `Arrays`。
- 掌握冒泡、最值、反转三个基础算法。
