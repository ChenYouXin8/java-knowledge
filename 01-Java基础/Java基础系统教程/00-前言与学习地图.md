# 《Java 基础系统教程》📘（电子版）

> 一本从零讲起、循序渐进的 Java 基础教程书。目标：**从完全不会，到能独立写出面向对象的小程序，并为 Spring / 面试打好地基。**
>
> 定位：**教学型**（讲懂"为什么"），与本目录上层的 8 篇**速查/面试笔记**（复习"记什么"）互补。

---

## 一、这本书参照了哪些市面经典书（编写规格）

本书的章节编排、深度与讲法，参照了以下公认经典，取各家之长：

| 参考书 | 作者 | 本书借鉴它的什么 |
|--------|------|------------------|
| **《Java 核心技术·卷 I（开发基础）》Core Java** | Cay S. Horstmann | **章节主线与严谨性**：类型→对象→继承→接口→异常→泛型→集合→并发的顺序，概念定义准确 |
| **《疯狂 Java 讲义》** | 李刚 | **知识点广度与中文讲解顺序**：覆盖国内求职需要的全部基础点，例子贴近中文学习者 |
| **《Java 编程思想》/《On Java 8》** | Bruce Eckel | **面向对象思想深度**：为什么一切皆对象、多态到底解决什么问题 |
| **《Head First Java》** | Kathy Sierra 等 | **讲法**：示例驱动、循序渐进、用图和对比代替干巴巴的定义 |
| **《Effective Java》** | Joshua Bloch | **最佳实践与避坑**：每章"工程实践/踩坑"小节，告诉你工作中该怎么写 |

> 版本基准：**JDK 17 / 21（LTS 长期支持版）**。涉及版本差异处会标注（如 JDK 8 / 9 / 17 的变化）。
> 开发工具：IntelliJ IDEA。

## 二、本书和已有笔记是什么关系

```
学习闭环：
  本书（教程，讲懂） → 动手敲代码 → 上层速查笔记（复习+面试题） → 刷题清单检验
```

- **看不懂概念** → 翻本书对应章节，有讲解、有图、有完整可运行例子

- **检验掌握程度** → 看 `java刷题路线/java-study-checklist.md` 对应模块打勾

## 四、建议学习顺序（两条路线）

**路线 A：零基础系统学（推荐，约 4-6 周）**
> 第 1→2→3→4 章（语法）→ 5→6→7 章（OOP，最重要，多花时间）→ 8→9→10→11 章（核心 API）→ 12→13→14→15 章按需

**路线 B：有其他语言基础，快速过（约 2 周）**
> 第 1 章环境 → 第 5/6/7 章重点看 Java 的 OOP 写法 → 第 11 章集合 → 其余当字典查

## 五、每章的固定结构（怎么用这本书）

1. **本章目标** — 学完能做什么
2. **概念讲解** — 用大白话 + 图讲清楚"是什么、为什么"
3. **完整代码示例** — 都能直接复制运行，带注释和运行结果
4. **工程实践 / 踩坑** — 工作里怎么写、容易错在哪（借鉴 Effective Java）
5. **本章小结** — 几句话回顾
6. **动手练习** — 必须自己敲，答案思路在附录
7. **延伸** — 链到对应速查/面试笔记

> 📌 学习铁律：**代码必须亲手敲、亲手跑**。看懂 ≠ 会写。每章练习做完再进下一章。
