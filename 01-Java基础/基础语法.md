# 基础语法

## 1️⃣ 代码模板

### 1-1 循环的 5 种写法

```java
// 模板1：标准 for 循环
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

// 模板2：倒序遍历
for (int i = n - 1; i >= 0; i--) {
    System.out.println(i);
}

// 模板3：增强 for（遍历数组/集合，推荐）
int[] arr = {1, 2, 3};
for (int x : arr) {
    System.out.println(x);
}

// 模板4：while（不确定循环次数时用）
Scanner sc = new Scanner(System.in);
while (sc.hasNextInt()) {
    int num = sc.nextInt();
    // 处理输入
}

// 模板5：do-while（先执行后判断，至少跑一次）
int count = 0;
do {
    count++;
    System.out.println("第" + count + "次执行");
} while (count < 3);
```

### 1-2 两数交换的 3 种写法

```java
// 方式1：临时变量（最标准）
int a = 1, b = 2;
int temp = a;
a = b;
b = temp;

// 方式2：加减法（注意溢出）
a = a + b;
b = a - b;  // b = 原a
a = a - b;  // a = 原b

// 方式3：异或（推荐，无溢出风险）
a = a ^ b;
b = a ^ b;  // b = 原a
a = a ^ b;  // a = 原b
```

### 1-3 数组初始化 4 种写法

```java
// 方式1：静态初始化（知道全部元素）
int[] arr1 = {1, 2, 3, 4, 5};

// 方式2：动态初始化（知道长度，不知内容）
int[] arr2 = new int[5];  // 默认值 0

// 方式3：先声明后赋值
int[] arr3;
arr3 = new int[]{10, 20, 30};  // 第二趟不能写 new int[3]

// 方式4：Arrays 初始化 + 赋值
int[] arr4 = new int[]{1, 2, 3};
Arrays.setAll(arr4, i -> i * 2);  // [2, 4, 6]
```

### 1-4 猜数字游戏（综合模板）

```java
Random rand = new Random();
int answer = rand.nextInt(100) + 1;  // 1~100
Scanner sc = new Scanner(System.in);

System.out.println("猜一个1-100的数：");
int guess;
int attempts = 0;
do {
    guess = sc.nextInt();
    attempts++;
    if (guess > answer) {
        System.out.println("太大了，再试：");
    } else if (guess < answer) {
        System.out.println("太小了，再试：");
    } else {
        System.out.println("恭喜！猜对了！用了" + attempts + "次");
    }
} while (guess != answer);
```

## 2️⃣ 对比表格

### 2-1 基本类型大小与默认值

| 类型 | 字节 | bit | 最小值 | 最大值 | 默认值 |
|------|------|-----|--------|--------|--------|
| `byte` | 1 | 8 | -128 | 127 | 0 |
| `short` | 2 | 16 | -32768 | 32767 | 0 |
| `int` | 4 | 32 | -2³¹ | 2³¹-1 | 0 |
| `long` | 8 | 64 | -2⁶³ | 2⁶³-1 | 0L |
| `float` | 4 | 32 | IEEE 754 | IEEE 754 | 0.0f |
| `double` | 8 | 64 | IEEE 754 | IEEE 754 | 0.0d |
| `char` | 2 | 16 | 0 ('\u0000') | 65535 ('\uffff') | '\u0000' |
| `boolean` | JVM未定 | 1 | — | true/false | false |

### 2-2 自动类型转换 vs 强制转换

| 方向 | 转换类型 | 是否需要强转 | 风险 |
|------|---------|------------|------|
| byte → short | 自动 | ❌ | 无 |
| short → int | 自动 | ❌ | 无 |
| int → long | 自动 | ❌ | 无 |
| long → float/double | 自动 | ❌ | 可能丢失精度 |
| double → long | 强制 | ✅ | 丢失小数部分 |
| float → int | 强制 | ✅ | 可能丢失精度 |
| int → byte | 强制 | ✅ | 数据截断 |
| int → char | 强制 | ✅ | 超过65535会错误 |

### 2-3 `break` / `continue` / `return`

| 关键字 | 作用范围 | 典型场景 |
|--------|---------|---------|
| `break` | 循环 / switch | 找到目标就退出 |
| `continue` | 循环 | 跳过本次，进入下次 |
| `return` | 方法 | 直接结束整个方法 |

### 3-2 switch 穿透 vs 箭头语法

```
传统写法（会穿透）：
┌─────────────────────────┐
│ case 1:  执行A; break;  │──→ 只执行A，跳出
│ case 2:  执行B;         │──→ 穿透，执行B和C
│ case 3:  执行C; break;  │──→ 执行完C，跳出
└─────────────────────────┘

箭头语法（不穿透）：
┌─────────────────────────┐
│ case 1 -> 执行A;        │──→ 只执行A
│ case 2 -> 执行B;        │──→ 只执行B
│ case 3 -> 执行C;        │──→ 只执行C
└─────────────────────────┘
```

### 3-3 数组内存模型

```
int[] arr = {10, 20, 30, 40};

栈内存（arr 变量）        堆内存（实际数组对象）
┌──────────────┐         ┌──────────────────────────┐
│ arr (引用)   │────────►│ [0] [1] [2] [3]         │
│ (指向堆)     │         │  10  20  30  40          │
└──────────────┘         │ index:0  1   2   3       │
                         │ length = 4               │
                         └──────────────────────────┘

二维数组内存：
int[][] matrix = {{1,2}, {3,4}};

栈                   堆
┌────────────┐       ┌──────┐
│ matrix ────┼──────►│ [0]──┼──► [1, 2]
└────────────┘       │ [1]──┼──► [3, 4]
                     └──────┘
```

## 5️⃣ 场景选择器

### 5-1 该用哪种循环？

```
需要遍历的元素是什么？
         │
    ┌────┴────┐
    │         │
  数组/集合   未知次数
    │         │
┌───┴───┐  ┌──▼──┐
│增强for │  │while │
│(只读) │  │循环  │
└───────┘  └──┬──┘
              │
         至少要执行一次？
              │
         ┌──┴──┐
         │ Yes │ No
         ▼     ▼
    do-while  while
```

### 5-2 该用哪种数据类型？

```
值域范围？
    │
┌───┴──────────────────────────┐
│ 小整数 -128~127              │──→ byte
│ 小整数 -32768~32767          │──→ short
│ 中整数 ±21亿                 │──→ int ✅（默认）
│ 大整数 ±9×10¹⁸               │──→ long
│ 小数（6-7位精度）             │──→ float
│ 小数（15位精度）              │──→ double ✅（默认小数）
│ 单个字符                      │──→ char
│ true/false                   │──→ boolean
└──────────────────────────────┘
```

### 5-3 何时需要强制类型转换？

```
源类型容量 ≥ 目标类型？
         │
    ┌────┴────┐
    │         │
   Yes        No
    │         │
  自动转换   ⚠️ 必须强转
  (安全)     (可能丢数据)
    │         │
    ▼         ▼
  无需写   (类型) 值
```

## 🐛 踩坑记录

- `switch` 的 `case` 不写 `break` 会**穿透**（Java 14+ 箭头语法不会）
- 数组声明 `int[] arr` 是推荐写法，`int arr[]` 是 C 风格
- `byte/short/char` 参与运算会**自动提升为 int**
- `Arrays.asList()` 返回的是**定长列表**，不能 add/remove
- 数组长度是 `.length`（**属性**，不是方法）
