# 集合框架

> List / Set / Map + ArrayList / HashMap / LinkedList 等。**面试必考**，实际开发天天用。

---

## 1️⃣ 代码模板

### 1-1 List 常用操作模板

```java
// 创建 + 添加
List<String> list = new ArrayList<>();
list.add("Java");
list.add("Python");
list.add(1, "Go");        // 指定位置插入
list.addAll(Arrays.asList("A", "B"));  // 批量添加

// 遍历（3种方式）
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}
for (String s : list) {
    System.out.println(s);
}
list.forEach(System.out::println);  // Lambda

// 查找
int index = list.indexOf("Java");   // 第一次出现位置
int last = list.lastIndexOf("Java"); // 最后一次出现位置
boolean has = list.contains("Go");

// 删除
list.remove(0);             // 按索引删
list.remove("Java");       // 按对象删（只删第一个）
list.removeIf(s -> s.length() > 4);  // Lambda 条件删除
list.clear();              // 清空

// 排序
Collections.sort(list);     // 自然顺序
list.sort(Comparator.comparingInt(String::length));  // 自定义排序
Collections.reverse(list);  // 反转

// 截取/子列表
List<String> sub = list.subList(0, 2);  // [0,2) 左闭右开

// 转换为数组
String[] arr = list.toArray(new String[0]);

// 复制
List<String> copy = new ArrayList<>(list);
```

### 1-2 Map 常用操作模板

```java
// 创建 + 添加
Map<String, Integer> map = new HashMap<>();
map.put("age", 18);
map.put("score", 100);
map.putIfAbsent("age", 25);   // key 不存在才插入
map.putAll(Map.of("a", 1, "b", 2));  // Java 9+

// 遍历（5种方式）
// 方式1：keySet + get
for (String key : map.keySet()) {
    System.out.println(key + "=" + map.get(key));
}
// 方式2：entrySet（推荐，性能最好）
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + "=" + entry.getValue());
}
// 方式3：Lambda forEach
map.forEach((k, v) -> System.out.println(k + "=" + v));
// 方式4：Stream
map.entrySet().stream().forEach(e -> System.out.println(e));
// 方式5：只遍历值
map.values().forEach(System.out::println);

// 查找
Integer val = map.get("age");           // 无则返回 null
Integer val2 = map.getOrDefault("name", 0);  // 无则返回默认值
boolean has = map.containsKey("age");
boolean has2 = map.containsValue(18);

// 删除
map.remove("age");              // 按 key 删
map.remove("age", 18);         // key=value 都匹配才删
map.clear();

// 替换
map.replace("age", 20);         // 替换值（key 存在才生效）
map.replace("age", 18, 25);    // 旧值匹配才替换
map.replaceAll((k, v) -> v * 2);  // 所有值翻倍

// 合并
map.merge("age", 10, Integer::sum);  // age 不存在则设为10，存在则求和
map.computeIfAbsent("len", k -> k.length());  // key不存在时才计算
map.computeIfPresent("age", (k, v) -> v + 1);  // key存在时才计算
```

### 1-3 Set 常用操作模板

```java
Set<String> set = new HashSet<>();
set.add("a");
set.add("a");           // 重复，添加失败，返回 false
set.addAll(Arrays.asList("b", "c"));

// 遍历
set.forEach(System.out::println);
for (String s : set) { System.out.println(s); }

// 查找
boolean has = set.contains("a");
set.isEmpty();
set.size();

// 删除
set.remove("a");
set.removeIf(s -> s.startsWith("a"));
set.clear();

// 集合运算
Set<String> s1 = Set.of("a", "b", "c");
Set<String> s2 = Set.of("b", "c", "d");

// 并集
Set<String> union = new HashSet<>(s1);
union.addAll(s2);  // [a, b, c, d]

// 交集
Set<String> inter = new HashSet<>(s1);
inter.retainAll(s2);  // [b, c]

// 差集（s1 有而 s2 没有的）
Set<String> diff = new HashSet<>(s1);
diff.removeAll(s2);  // [a]
```

### 1-4 HashMap 初始化模板（性能优化）

```java
// ❌ 错误：默认容量 16，每次扩容翻倍，要 resize 多次
Map<String, Object> map1 = new HashMap<>();

// ✅ 正确：预估容量，避免扩容
// 预期 1000 个元素，容量 = 1000 / 0.75 + 1 ≈ 1334，取 2^n → 2048
Map<String, Object> map2 = new HashMap<>(2048);

// ✅ Java 9+：of() 创建只读 Map
Map<String, Integer> map3 = Map.of("a", 1, "b", 2);

// ✅ 创建不可变 Map（线程安全，推荐用于常量）
Map<String, Integer> constant = Map.ofEntries(
    Map.entry("DEBUG", 1),
    Map.entry("INFO", 2)
);
```

### 1-5 集合转字符串模板

```java
// 用逗号连接 List 元素
List<String> names = Arrays.asList("Tom", "Jerry", "Mike");
String result = String.join(", ", names);  // "Tom, Jerry, Mike"

// 用 Stream 转字符串
String stream = names.stream()
    .collect(Collectors.joining(", "));

// Map 转字符串
Map<String, Integer> map = Map.of("a", 1, "b", 2);
String mapStr = map.entrySet().stream()
    .map(e -> e.getKey() + "=" + e.getValue())
    .collect(Collectors.joining(", "));
```

## 2️⃣ 对比表格

### 2-1 List 三剑客对比

| 特性 | ArrayList | LinkedList | Vector |
|------|---------|-----------|--------|
| 底层结构 | 动态数组 | 双向链表 | 动态数组 |
| 随机访问 | O(1) ✅ | O(n) ❌ | O(1) |
| 头插/删 | O(n) | O(1) ✅ | O(n) |
| 中间插/删 | O(n) | O(n) | O(n) |
| 线程安全 | ❌ | ❌ | ✅（已过时） |
| 内存占用 | 低 | 高（每节点多24字节） | 低 |
| 扩容机制 | 1.5 倍 | 无需扩容 | 2 倍 |
| 使用场景 | 随机访问为主 | 头尾操作为主 | 不用（用 Collections.synchronizedList） |

### 2-2 Map 三剑客对比

| 特性 | HashMap | LinkedHashMap | TreeMap |
|------|---------|--------------|---------|
| 底层结构 | 数组+链表+红黑树 | HashMap + 双向链表 | 红黑树 |
| 顺序 | 无序 | 插入顺序 | key 自然排序 / 自定义 |
| 线程安全 | ❌ | ❌ | ❌ |
| null key | 允许 1 个 | 允许 1 个 | 不允许 |
| null value | 允许多个 | 允许多个 | 允许多个 |
| 查找/插入 | O(1) ~ O(log n) | O(1) ~ O(log n) | O(log n) |
| 使用场景 | 通用缓存、统计 | 需要保留顺序 | 需要 key 排序 |

### 2-3 HashMap / HashTable / ConcurrentHashMap 对比

| 特性 | HashMap | Hashtable | ConcurrentHashMap |
|------|---------|---------|-----------------|
| 线程安全 | ❌ | ✅（全表锁） | ✅（分段/桶锁） |
| null key | 允许 | ❌ 不允许 | ❌ 不允许 |
| null value | 允许 | ❌ 不允许 | ❌ 不允许 |
| 并发性能 | — | 差（全局锁） | 好（CAS+sync） |
| 迭代安全性 | fail-fast | fail-safe（遍历快照） | fail-safe |
| 替代方案 | — | — | ✅ 推荐 |

### 2-4 Set vs List vs Map 关系

| 集合 | 底层对应 | 特点 | 典型用途 |
|------|---------|------|---------|
| `HashSet` | HashMap（只 key） | 无序、唯一 | 去重 |
| `LinkedHashSet` | LinkedHashMap | 保留插入顺序 | 按顺序遍历+去重 |
| `TreeSet` | TreeMap | key 排序 | 有序去重、排行榜 |
| `ArrayList` | Object[] | 有序、可重复、随机访问快 | 列表、缓存 |
| `LinkedList` | 双向链表 | 有序、可重复、头尾增删快 | 队列、栈 |

## 3️⃣ 图解结构

### 3-1 HashMap put 流程（面试必背）

```
put("name", "Tom")

① 计算 key 的 hash = key.hashCode()
② hash ^= (hash >>> 16)         ← 高低位混合
③ index = (n - 1) & hash        ← 计算数组下标

④ 位置为空？
    │
  ┌─┴──────────────────────────┐
  │ 是                        │ 否
  ↓                          ↓
  直接放入                ④-1 key.equals() 相同？
  (数组节点)                  │
                        ┌─────┴──────────┐
                       是               否
                        ↓                ↓
                    覆盖 value        链表/红黑树追加
                        │
                    ⑤ size++，检查是否扩容
                    (容量 * 负载因子 > size)
```

### 3-2 HashMap 扩容机制

```
初始：容量=16，负载因子=0.75
第 12 个元素存入后 → 触发扩容 → 容量翻倍 16→32

┌──────────────────────────────────────────┐
│  扩容前（16）       扩容后（32）         │
│  ┌──┬──┬──┐       ┌──┬──┬──┬──┐        │
│  │  │  │  │  →   │  │  │  │  │        │
│  └──┴──┴──┘       └──┴──┴──┴──┘        │
│  下标: 0~15        下标: 0~31           │
│                   所有节点重新计算 index  │
└──────────────────────────────────────────┘

扩容是 O(n) 操作，所以预估容量很重要！
```

### 3-3 红黑树 vs 链表转换

```
链表长度 ≥ 8 且数组长度 ≥ 64  →  转红黑树（查询 O(log n)）
红黑树节点数 ≤ 6              →  转回链表（避免节点稀疏）

[桶] → ○ → ○ → ○ → ○ → ○ → ○ → ○ → ○
                     ↑
              第8个节点，触发树化
              链表长度 = 8，容量 ≥ 64
```

## ❓ 常见面试题

**Q1: ArrayList vs LinkedList 怎么选？**
> 详见上方对比表格 2-1。
**Q2: HashMap 的 hash 为什么要 `^ (h >>> 16)`？**
> 高低位混合，让高位也参与 index 计算，减少哈希冲突。
**Q3: 为什么 HashMap 容量是 2 的 n 次方？**
> `(n-1) & hash` 比 `hash % n` 更快；且保证下标均匀分布。
**Q4: HashMap 为什么线程不安全？**
> JDK 7 头插法扩容可能死循环；JDK 8 尾插法不死循环，但仍可能数据覆盖/丢失。
**Q5: 什么是 fail-fast？**
> 迭代过程中集合被修改会抛 `ConcurrentModificationException`，用迭代器的 `remove()` 或 `CopyOnWriteArrayList` 可避免。

## 🐛 踩坑记录

- HashMap 的 `key` 必须正确重写 `equals()` 和 `hashCode()`
- 不要在遍历时用 `list.add/remove()`，要用迭代器或 `removeIf()`
- 初始化 HashMap **预估容量**：`new HashMap<>(预期大小 / 0.75 + 1)`
- `subList()` 返回的是**视图**，修改会影响原集合
- `Arrays.asList()` 返回的是定长列表，不能 add/remove
